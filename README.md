# Kaboomando

A 90s-arcade style run-and-gun adventure for mobile browsers — an original game by **P-Prece Studio (พีพีช Studio)**.

Two young commandos, Tiko and Mira, blast an army of toy robots across endless procedurally generated stages (8 world themes that cycle with new color variations) and giant bosses. Portrait touch controls, 21 languages (`?lang=xx`), PWA, procedural pixel art and WebAudio music.

All art, characters, music and code are original. Play: https://pawineenueangnin-oss.github.io/kaboomando/
